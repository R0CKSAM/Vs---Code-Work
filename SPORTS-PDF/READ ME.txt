Double-click Extract Sports.lnk, select one or more downloaded newspaper PDFs, and wait.
Progress appears in the console. Output goes into SPORTS_ONLY beside each input PDF.
Originals are untouched. Existing output filenames are numbered instead of overwritten.

Image-only scans are supported using local OCR. It checks section headings in the top 11.5% of each page.
Only pages headed SPORTS / TIMES SPORT / TIMES SPORTS are included; sports articles on the front page are excluded.
OCR can miss unusual/unclear headings. A per-page scan CSV is saved for review.
If no headings match, no empty PDF is created. Use --pages to select known pages manually.
Original page images and layout are copied, not re-rendered. No additional image quality loss.

AUTOMATIC WATCHER
Start Watcher.lnk processes existing and incoming PDFs in all edition subfolders under:
C:\Users\Intern\Downloads\Storyboard Studio\InduPaper
It skips SPORTS_ONLY and recognizes already extracted outputs.
New PDFs must remain stable for 20 seconds and have a valid PDF end marker before processing.
One paper is processed at a time at below-normal Windows priority.
Progress: watch_status.json (current file and counts) and watcher.log (page-by-page detail).
Stop: close the watcher's terminal with Ctrl+C, or create STOP_WATCHER.txt beside this script.
The stop file takes effect after the current PDF finishes. The next manual start clears it.
The watcher must remain running for incoming files. It is not installed as a Windows startup task.
OCR failures/no matching Sports heading are recorded for review, not retried indefinitely.

MERGE IN DATE ORDER
Double-click Merge PDFs by Date.lnk and select either the delhi folder (full papers) or SPORTS_ONLY (sports pages).
Reads YYYY-MM-DD from filenames, sorts oldest first, and includes all pages of each PDF.
One folder only, non-recursive. Output is saved under its MERGED subfolder.
Adds a bookmark per date, a CSV page index, and a JSON report listing missing dates.
Existing files are preserved. Duplicate dates stop with a clear message; use one edition/copy per date.
This merges the files currently present; it does not automatically append incoming files. Run again after downloads finish.
Command:
"D:\Vs - Code Work\venv\Scripts\python.exe" -X utf8 -u "D:\Vs - Code Work\SPORTS-PDF\merge_pdfs_by_date.py" "C:\Users\Intern\Downloads\Storyboard Studio\InduPaper\delhi\SPORTS_ONLY"

AI-READABLE OCR DOCUMENTS
Double-click Create AI OCR PDFs.lnk and choose an original merged newspaper scan.
The tool creates three documents in AI_OCR beside the source:
1. *_SEARCHABLE.pdf: newspaper images with an invisible, searchable OCR text layer.
2. *_AI_TEXT.pdf: small text-only PDF with the same page layout and date bookmarks; suited to AI uploads.
3. *_AI_TEXT.txt: UTF-8 transcription with dates, merged-page numbers and original newspaper-page numbers where known.

Libraries: PyMuPDF for PDF handling; Windows.Media.Ocr for local English OCR, called through windows_ocr.ps1.
Windows OCR is built into this PC. No document is uploaded to an OCR service.
OCR reads the original-quality PDF at 240 DPI. When a matching *_COMPACT.pdf exists, its images are used in the searchable output to keep file size down.
OCR may misread small text, names, scores and column order. Compare important facts against the image PDF.
Images/charts are retained in SEARCHABLE.pdf; AI_TEXT.pdf/TXT contain recognized text, not the pictures.
Progress: ocr_status.json, and AI_OCR\progress.json beside the source.
Completed pages are cached; rerun the same command to resume after an interruption.
Cache contents are local OCR text/word coordinates. Keep them for resuming.
English Windows OCR language support must be installed. Input/output PDFs and other original files are preserved.
Tests: python tests/test_ocr.py
