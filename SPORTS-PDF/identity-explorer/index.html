Rows are first-observed calendar weeks in the complete file. Cells show observed activity within the selected scope. The data is not a complete daily calendar, so this is an observation matrix—not certified retention or churn. “—” means no source dates for that calendar week or a future period.

A defensible measurement contract

1. Count the thing you actually observe

Report distinct client IPs, distinct device IDs and signed-in User-IDs separately. This file has no signed-in User-ID. A device ID is not proof of a physical device or a person.

2. Do not merge people through an IP

A household, office or carrier can share an address. A device can change addresses. The graph records direct associations only; connected components are not unique-user counts. UA is context, not a reliable person identifier.

3. Declare scope and cohort baseline

Deduplicate across all selected events/dates for a scope total. Never add daily distincts. Returning IDs are evaluated against the complete file's first-observed date, even when the displayed date/event scope is narrower.

4. Show identity coverage

Missing identifiers remain unknown. Do not assign an IP-only record to a device just because another record shares its IP. Most device IDs in this file sit on zero-TS rows; device watch hours cannot be attributed from those rows.

5. Collect what a true journey needs

For future instrumentation: a stable first-party installation ID, opaque account User-ID when signed in, UTC event timestamp, session/playback ID, content/event ID, event type and measured playback heartbeat. Keep IP and UA as context. Record identity creation/reset and consent state.

6. Separate observation from inference

Many IPs per ID may be ordinary mobility or ID reuse. Many device IDs per IP may be a shared network. Daily data cannot prove exact viewing sequence, concurrent usage, precise location, household membership or fraud.

Source and limitations

This is an offline snapshot explorer. It does not monitor browser activity, send logs to an analytics service, or modify the original Parquet. Full raw UA, session IDs and player event timestamps are absent from the supplied file.
