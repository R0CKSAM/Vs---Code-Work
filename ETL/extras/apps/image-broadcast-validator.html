Broadcast Image Validator

Select one or more images — checks resolution, aspect ratio, and orientation against common live-broadcast / ad-break standards.

Validated against: HD 1920×1080 (16:9), UHD/4K 3840×2160 (16:9), PAL SD 1024×576 (16:9 broadcast-safe), Square 1080×1080 (1:1), Vertical 1080×1920 (9:16).
Pass = exact match to a standard. Warn = correct ratio, non-standard resolution (will scale cleanly). Fail = ratio doesn't match any standard (will letterbox/crop on air).
