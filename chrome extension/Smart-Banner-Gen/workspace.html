How exact-size saving works

Generated files are measured before saving. Wrong-size originals go into bin. The extension then asks ChatGPT in the same conversation for a real downloadable PNG at the exact dimensions, preserving the thumbnail content. It checks the returned file again and accepts only an exact match. Up to two follow-ups are allowed; then it pauses for review. There is no local resizing, padding or stretching. Correct dimensions do not prove correct wording: review artwork before publishing.

Folders: category / 1920 × 1080 px / vod_key.png and category / 400 × 711 px / vod_key.png. Rejected files go to category / bin. Folder access requires your selection, because Chrome cannot silently access a D: path.

The extension uses ChatGPT’s website interface, which can change. A conversation change, missing upload confirmation or ambiguous response pauses the queue. It never automatically resends a possibly submitted prompt.
