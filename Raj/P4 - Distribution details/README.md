# Channel Distribution Dashboard — P4

A data pipeline and interactive HTML dashboard for tracking **headend-level channel distribution**, weekly LCN assignments, and week-over-week channel comparison across cable networks in India.

## 🚀 Workflow

### 1. Add New Weekly Data
Place the new week's Excel workbook (`.xlsx`) into:
```
Data/raw/
```
The file will be automatically renamed to a canonical week label (e.g. `2026'Week31.xlsx`) during processing.

### 2. Run the Update Pipeline
From the project root (with the virtual environment activated):
```powershell
# Activate environment
.venv\Scripts\Activate

# Process new workbooks incrementally
python update.py

# Rebuild everything from scratch (re-processes all workbooks)
python update.py --rebuild
```

This will:
- Move files from `Data/raw/` → `Data/processed/`
- Parse each workbook and extract headend & channel data
- Merge results into `processed/distribution_master.json`, `channel_weekly.json`, and `headend_weekly_history.json`
- Generate `processed/channel_review_suggestions.json`

### 3. Build the Dashboard JSON (for `index.html`)
The `index.html` dashboard loads JSON files from `dashboard/data/`. These are auto-generated by `scripts/update.py` via `python/db.py`.

### 4. Build the Standalone Dashboard (Optional)
To generate a single self-contained HTML file with all data embedded:
```powershell
python scripts/build_dashboard.py
```
Output: `dashboard/dashboard_output.html`

## 📊 Dashboard — Tables Overview

| Table | Description |
|-------|-------------|
| **Table 1 — Distribution Master** | Latest headend snapshot: Network, Location, State, BARC Market, STBs, Landing & Barker channels |
| **Table 2 — Weekly Channel History** | Week-by-week LCN assignments per headend; filterable by channel, week range, and change status |
| **Table 3 — Weekly Landing / Barker History** | Landing Channel and Barker channel week-over-week comparison with combined **Channel Name - LCN** display |

### Table 3 — Column Format
In Table 3, the **Landing Channel Name** and **LCN Number** are combined into a single column:
- Example: `News18 India - 305`
- If no LCN is available: `News18 India`
- If no data: `NA`

## 🔧 Normalization

The parser applies normalization for:

| Field | File |
|-------|------|
| State names | `parser.py` → `STATE_NORMALIZATION` |
| City / Headend Location | `parser.py` → `CITY_NORMALIZATION` |
| BARC Market | `parser.py` → `BARC_MARKET_NORMALIZATION` |
| Channel Names | `scripts/channel_normalization.json` |

To add a new channel alias, edit `scripts/channel_normalization.json`:
```json
{
  "News 18 India HD": "News18 India",
  "Aaj Tak HD": "Aaj Tak"
}
```

---

## 📝 Notes

- Workbooks must follow the expected format: header rows in rows 1–10, LCN/Channel blocks starting at row 11.
- Week labels are auto-derived from filenames (e.g. `2026 Week 31.xlsx` → `2026'Week31`).
- Duplicate workbooks for the same week are moved to `Data/copy/` automatically.
- The `dashboard/index.html` requires a local web server (e.g. VS Code Live Server) to load JSON files due to browser CORS restrictions.
- `dashboard_output.html` is fully self-contained and can be opened directly in any browser.
